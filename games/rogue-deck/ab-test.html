Rogue Deck: A/B Test Plan

My playtest logs showed that players almost never buy Common Rogue effects. This page plans the A/B test I would run once Rogue Deck is live: hypothesis, metrics, sample size, analysis and the rules for deciding whether to ship.

The baseline comes from my real playtest logs. Rogue Deck isn't live yet, so the experiment result further down is simulated, using assumed traffic and effect sizes. The analysis code produces every number on this page and can be run on real logs later without changes.

VariantShop shows each offer's expected gain and payback

1. The problem

The Rogue shop always shows three effects to choose from. Commons are the most common rarity (weights 8/4/2/1), so more than half of all offers are Common. But in 20 logged playtest matches, players bought 266 Rogue effects, and only 6 of them were Common.

According to the balancing model, Commons aren't bad buys. Here's an example offer, with values from the model at a mid-match score of about 100 points:

OfferRarityCostExpected gainNetPayback
Score Multiplier: Hearts ×2Common10+27+172.7×
Score Multiplier: Red ×2Rare20+54+342.7×
Score Multiplier: Hearts ×5Legendary40+68+281.7×

Expected gain: extra points the effect earns over the rest of the match. Net: gain minus cost. Payback: how many times the effect earns back its cost. All values from the balancing spreadsheet.

For its price, the Common is as good as the Rare and better than the Legendary. But you can only own a limited number of Rogue effects, and per effect the Common adds the fewest points. On the other hand, it's cheap, so your score stays higher and you unlock the next Rogue slot sooner.

Which choice wins over a whole match can't be answered by the model alone. That's why it's tested with real players, and why final score is one of the guardrails.

2. Hypothesis & variant

Hypothesis

Players pick Rogue offers by rarity, not by what they're worth. If the shop shows how many points each offer is expected to earn, players will pick Commons more often when they're the better deal. Match scores, match length and retention should stay the same.

  • Only one thing changes. Prices and rarity odds stay the same; only the shop shows more information. So any difference comes from the information alone. Lowering the Common price would be a separate test later.
  • Points and payback are both shown. Payback alone would make Commons look best even when a Rare earns more points. Showing both lets players decide for themselves.

Mixed matchesAllowedPlayers from both groups can meet in the same match. Common Rogue effects only raise the buyer's own score, so the new shop doesn't change anything for their opponents.

GuardrailFinal scoreScores drop by less than 5% (players must not be pushed into worse buys)

Primary is what the test tries to improve. Guardrails are things that must not get worse. A guardrail only passes if the data shows any harm is smaller than the limit. "No visible difference" isn't enough, because a small test can miss a real problem.

Retention decides the test size, not the Common share. Measuring the Common share needs only a few hundred players, but checking retention needs thousands. 6. Analysis plan

These rules are fixed before the test starts, so the result can't change how it's analysed:

  • No early stopping. The test runs the full 14 days, even if the result looks clear after day one. Results that look clear early are often just chance. The test only stops early for a bug or a serious problem with a guardrail.
  • Check the group sizes first. Both groups should be about the same size. If they're clearly uneven (p < 0.001), players are being sorted into groups wrongly, and nothing else is analysed until that's fixed.
  • Count players, not just purchases. Players are split into groups, not purchases, and one player's purchases are similar to each other. The confidence interval accounts for this (delta method with players as clusters). A bootstrap that resamples whole players double-checks it.
  • Check for novelty. Compare week 1 with week 2. Players may try the new shop just because it's new, so the release plan uses the week 2 result.
  • Breakdowns are only for understanding. New vs existing players, 2- vs 4-player matches and game modes help explain the result. They're never used to turn a failed test into a success.

7. Simulated result

This is simulated data: 24,000 made-up players with assumed behaviour, run through the analysis code above (seed 42). It shows how the test would be analysed and decided, not how real players would react.

Groups: 11,904 vs 12,096 players. That's close enough to an even split (p = 0.22), so players were sorted into groups correctly.

Players who saw the expected value bought 75% more Commons. Even the low end of the range is well above zero, so this isn't chance. The bootstrap check gives almost the same range (+1.60 to +1.85 pp).

The same-player effect was a bit stronger than planned (2.61 instead of 2.28), because some players play far more matches than others. The test still had far more data than it needed.

The effect is slightly smaller in week 2, as some players stop paying attention to the new line. So the week 2 result is the one to plan with.

All guardrails pass, but two of them really did change, just by less than the limit:

  • Matches got slightly longer, because players take a moment to read the new line.
  • Final scores dropped by 1%, which fits Commons adding fewer points per slot.

Both are worth watching after release.

5% keep the old shop for 4 weeksCatches smaller retention changes (D7, D28) and long-term score changes

What would change the decision

  • Commons don't go up clearly: showing the value alone doesn't change how players buy. Next step: test a lower Common price instead.
  • Final score drops by more than 5%: the new shop pushes players into worse buys. Next step: show only the net points, or make Commons stronger before showing their value.
  • Matches get more than 5% longer: the shop takes too long to read. Next step: show just one number per offer and test again.

Follow-up test

If players still rarely buy Commons after the release, the next test changes the price instead, for example 5% of your score instead of 10%. It uses the same metrics and guardrails.
